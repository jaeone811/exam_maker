# 모의고사 메이커

평가원·교육청 모의고사 시험지 양식 그대로 나만의 모의고사를 만드는 웹 편집기.
문항을 쓰면 A4 2단 시험지로 자동 조판되고, 브라우저 인쇄로 PDF까지 뽑을 수 있음.

## 실행

설치할 거 없음. 아래 중 하나로 열면 됨.

- `index.html`을 크롬/엣지로 바로 열기
- 또는 로컬 서버: `python3 -m http.server` 실행 후 http://localhost:8000
- GitHub Pages를 켜면 어디서든 접속 가능 (Settings → Pages → 브랜치 선택)

수식 엔진(KaTeX)은 `vendor/`에 들어 있어서 인터넷 없이도 수식이 나옴.
글꼴은 한글(HWP)이 깔린 PC면 한양신명조·HY견고딕을 먼저 쓰고, 없으면 Noto Serif KR / Noto Sans KR(구글 폰트)로 대체함.

## 지원하는 시험지 양식

| 요소 | 내용 |
|---|---|
| 첫 쪽 머리글 | 시험 이름 한 줄, 교시 타원, 영역명(+선택과목명), 홀수형/짝수형 표시, 성명·수험번호·'제 [ ] 선택' 칸 |
| 둘째 쪽부터 | 영역명 머리글, 쪽 번호가 홀수 쪽은 오른쪽·짝수 쪽은 왼쪽 |
| 본문 | 2단 + 가운데 세로줄, 문항 번호 내어쓰기, 배점 `[3점]` 자동 |
| 배치 방식 | **풀이 공간형**(수학: 단을 칸으로 나눠 문항 사이 풀이 공간 확보) / **밀집형**(탐구·국어: 이어서 채우고 남는 공간 고르게 분배) |
| 유형 라벨 | `5지선다형` / `단답형` 상자 자동 |
| 선택지 | ①~⑤ 폭을 재서 한 줄 5개 → 3+2 → 한 줄에 하나 자동 결정 (4지선다도 가능) |
| 상자 | 조건 (가)(나), `<보 기>` ㄱㄴㄷ, 자료 상자(제목), 둥근 상자, 네모 빈칸 |
| 표·그림 | 머리행 음영, 칸 병합, 그림 크기·정렬·캡션, 나란히 배치 |
| 지문 (국어) | 번호 없는 지문 칸. 뒤 문항으로 `[1～3] 다음 글을 읽고 물음에 답하시오.` 자동, 문단 첫 줄 들여쓰기·양쪽 정렬, 단·쪽이 모자라면 글줄 단위로 끊어서 다음 단에 이어 실음 |
| 말풍선 (탐구) | 실제 시험지 그림을 올리고(캡처 후 Ctrl+V 가능) [글 넣기]에서 말풍선 위에 글상자 배치, 흰 가리개로 원래 글자 지우기, 그림 자르기. 그림 없이 `[대화]` 문법으로 말풍선 대화도 가능 |
| 묶음 | 공통 + 선택과목(확통/미적/기하) 따로, 선택과목마다 23번·1쪽부터 다시 시작 |
| 끝 처리 | 묶음 끝 `＊ 확인 사항` 상자, 아래 `n / 전체` 쪽 표시 |
| 부록 | 정답표(배점 포함), 해설지(2단) 자동 생성 |
| 용지 | A4 기준 조판, B4·A3로 확대 인쇄 |

## 시험지 틀

[새 시험지]에서 고름.

- **수학 30문항 (공통 22 + 선택 8)**: 평가원 수학 배점 그대로 (1~2번 2점, 3~8번 3점, 9~15번 4점, 16~19번 3점, 20~22번 4점 / 23번 2점, 24~27번 3점, 28~30번 4점 = 공통 74 + 선택 26 = 100점)
- **수학 30문항 (선택과목 없음)**
- **탐구 20문항 (학평 스타일)**: 2점 10개 + 3점 10개 = 50점
- **국어 45문항 (공통 34 + 선택 11)**: 공통 1~34, 화법과 작문 / 언어와 매체 35~45. 지문 칸 포함
- 예시 시험지 3종(수학·국어·탐구), 빈 시험지

배점은 0.5 단위로 자유롭게 바꿀 수 있음 (2028 수능 통합사회·통합과학의 1.5/2/2.5점 같은 배점도 가능).

## 본문 작성 문법

엔터 한 번 = 시험지에서도 줄바꿈, 빈 줄 = 문단 간격.

| 쓰는 법 | 결과 |
|---|---|
| `$f(x)=x^2$` | 수식 (LaTeX). 달러 자체는 `\$` |
| `$$ \lim_{x\to1}f(x)=3 $$` | 들여쓴 한 줄 수식 (`$$가운데 ...$$`는 가운데) |
| `**굵게**`, `__밑줄__` | 옳지 __않은__ 것은? |
| `[[(가)]]` | 네모 칸 |
| 줄 맨 앞 `(가)`, `ㄱ.`, `㉠`, `◦`, `①` | 내어쓰기 |
| `[가운데] …`, `[오른쪽] …`, `[들여] …` | 줄 정렬 |
| `[조건] … [/조건]` | 조건 상자 |
| `[보기] … [/보기]` | `<보 기>` 상자 (`[보기 자료]`처럼 제목 변경) |
| `[박스 제목] … [/박스]`, `[둥근박스] … [/둥근박스]` | 자료 상자 |
| `[표 머리 전체] … [/표]` | 표. 칸은 `\|`, `!칸` 음영, `{2}칸` 가로 병합, `{1x2}칸` 세로 병합, `^` 병합된 자리 |
| `[그림1 60% 오른쪽 캡션]` | 올린 그림 |
| `[나란히] A [\|] B [/나란히]` | 옆으로 나란히 |
| `[점수]` | 배점 들어갈 자리 지정 (안 쓰면 마지막 문장 끝) |
| `[대화]` 줄마다 `갑: …` `[/대화]` | 말풍선 대화 (`[대화 교대]`는 좌우 번갈아) |

## 국어 지문 넣기

1. 목록에서 **[+ 지문]** → 지문 칸이 생김 (번호 없음)
2. 지문 바로 아래에 문항들을 둠. 머리말의 `[1～3]`은 뒤따르는 문항 번호로 자동 계산 (`묶을 문항 수`로 제한 가능, 비우면 다음 지문 전까지)
3. 지문 본문은 **한 줄 = 한 문단**. 빈 줄은 문단 사이 띄움(시의 연 구분 등). 시는 '문단 첫 줄 들여쓰기'를 끄면 됨
4. 머리말은 `{범위} 다음은 학생의 발표이다. 물음에 답하시오.`처럼 바꿀 수 있음
5. '지문을 상자로 감싸기'를 켜면 지문 전체에 테두리. 단·쪽이 넘어가면 단마다 테두리를 닫고 다음 단에서 다시 엶
6. 밀집형 배치에서는 지문이 단 끝에 걸리면 글줄 사이에서 잘라 다음 단·쪽에 이어 실음. 그림·표·상자는 자르지 않고 통째로 넘김

## 말풍선 그림 채우기 (탐구)

1. 실제 시험지에서 학생들이 대화하는 그림을 캡처 → 본문 입력칸에서 **Ctrl+V** (또는 [그림 올리기])
2. 그림 카드의 **[글 넣기]** → 큰 편집 창이 열림
3. 말풍선 안을 **두 번 클릭**하면 그 자리에 글상자 생성. 끌어서 옮기고, 오른쪽 아래 파란 점으로 크기 조절, 방향키로 미세 이동
4. 원래 그림에 글자가 있으면 **[+ 흰 가리개]**로 덮거나, 글상자의 '바탕을 흰색으로'를 켬
5. 필요 없는 부분은 **[그림 자르기]** → 남길 영역을 끌어서 선택
6. 글상자 위치는 그림 크기에 대한 비율로 저장돼서, 본문에서 `[그림1 80%]`처럼 그림 폭을 바꿔도 같은 자리에 유지됨

예시:

```
최고차항의 계수가 $1$인 이차함수 $f(x)$가 다음 조건을 만족시킬 때, $f(4)$의 값을 구하시오.
[조건]
(가) $f(1)=f(3)$
(나) $f(0)=5$
[/조건]
```

## 저장 · 인쇄

- 작업 내용은 브라우저에 자동 저장됨. 다른 PC로 옮기거나 백업하려면 **저장(.json)** → 나중에 **불러오기**.
- **인쇄 · PDF** → 대상 'PDF로 저장', 여백 '없음', 배율 100%, '배경 그래픽' 켜기. 크롬/엣지 권장.
- 미리보기에서 문항을 누르면 그 문항 편집으로 바로 감. 한 단보다 긴 문항은 빨간 점선 + 경고 표시.
